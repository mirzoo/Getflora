# ReBloom

ReBloom is an MVP concept for a flower resale marketplace: people can publish
gifted bouquets they do not need and buyers can find fresh flowers cheaper.

## MVP

- Browse flower listings
- Filter by city and max price
- Add a temporary listing from the page
- Static frontend with no backend yet

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
