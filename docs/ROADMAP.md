# Roadmap

## Ближайший фокус

1. Проверить вручную A/B-сценарии:
   - пользователь A публикует объявление;
   - пользователь B добавляет его в избранное;
   - пользователь B покупает и пишет продавцу;
   - пользователь A видит чат с покупателем;
   - пользователь A отмечает объявление как проданное.

2. Редактирование своего объявления:
   - цена;
   - описание;
   - район;
   - состав;
   - ссылки на фото.

3. Улучшить раздел `Мои объявления`:
   - статусы;
   - пустые состояния;
   - отдельное отображение проданных.

## Потом

- Настоящая загрузка фото в S3-compatible storage.
- Нормальная авторизация: magic link или пароль.
- Подтверждение email.
- Production cleanup через cron/background job.
- Деплой на Docker/VPS.

## Пока не делать

- Не подключать внешние auth-сервисы.
- Не подключать платежи.
- Не усложнять storage, пока форма объявления и seller workflow не стабилизированы.
